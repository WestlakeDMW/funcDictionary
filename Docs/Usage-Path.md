# funcDictionary 使用路径

当前 macOS 主流程：添加项目 → 复制接入说明 → 由已有 Agent 建立词典 → App 自动接收入库 → 搜索与查看。

1. 在「添加项目」中选择源码目录，重复添加会复用已有项目。
2. 将「复制接入说明」交给正在使用的 Agent，并让它保留原有规则，把维护流程接入实际读取的规则入口。
3. Agent 阅读实现与调用处，按模块分批提交；检查 applied 回执后再继续。
4. 在 App 中输入中文描述、函数名或旧称，查看用途、代码位置、已记录的调用方与历史。
5. 用「编辑说明」补充自己的叫法和备注，用「复制定位信息」与 Agent 交流。
6. 后续编程由 Agent 按规则同步词典。App 运行时处理已关联且可访问项目的增量，不要求切换到该项目。

pending 表示等待入库，不能当成同步成功。App 退出期间的增量保留，重新运行后处理；版本过期时重新读取词典并计算变更。

只有说明文件存在不能证明 Agent 会执行，真实多 Agent 连续交接和无需提醒的流程仍待验证。旧 Harness 中心和常态审批不再是日常使用入口。

构建命令、CLI 示例与使用事项见 [中文 README](../README.md) 和 [English README](../README.en.md)。本初版的验证范围见 [开源验证记录](OpenSourceReadiness.md)。
